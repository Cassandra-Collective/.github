# Getting help

This guide covers every repository in the [Cassandra Collective](https://github.com/Cassandra-Collective) organisation that does not have a `SUPPORT.md` of its own.

## Where to ask

Ask in the repository your question is about, as an issue labelled `question`:

| Project | Ask a question | Earlier questions |
|---|---|---|
| CASSANDRA | [New issue](https://github.com/Cassandra-Collective/CASSANDRA/issues/new/choose) | [`question` issues](https://github.com/Cassandra-Collective/CASSANDRA/issues?q=is%3Aissue+label%3Aquestion) |
| CASSANDRA-Chorus | [New issue](https://github.com/Cassandra-Collective/CASSANDRA-Chorus/issues/new/choose) | [`question` issues](https://github.com/Cassandra-Collective/CASSANDRA-Chorus/issues?q=is%3Aissue+label%3Aquestion) |
| Dervish | [New issue](https://github.com/Cassandra-Collective/Dervish/issues/new/choose) | [`question` issues](https://github.com/Cassandra-Collective/Dervish/issues?q=is%3Aissue+label%3Aquestion) |
| Ephesus | [New issue](https://github.com/Cassandra-Collective/Ephesus/issues/new/choose) | [`question` issues](https://github.com/Cassandra-Collective/Ephesus/issues?q=is%3Aissue+label%3Aquestion) |
| `.github` (profile and brand) | [New issue](https://github.com/Cassandra-Collective/.github/issues/new/choose) | [`question` issues](https://github.com/Cassandra-Collective/.github/issues?q=is%3Aissue+label%3Aquestion) |

Where a repository offers a **Question** form, use it: it adds the label for you. Where it does not, or you cannot set labels, start the title with "Question:" and a maintainer will label it.

If your question is about the organisation as a whole, ask it in the `.github` repository.

## Before you ask

- Read the repository's README and its `docs/` folder, if it has one.
- Search the repository's issues, open and closed. Your question may already have an answer.

## What to include

- What you are trying to do, not only the step that failed.
- What you tried: the exact commands, and their output as text rather than a screenshot.
- The commit or version, your operating system, your Python (or other runtime) version and, for training or inference, your hardware (GPU and its memory, or CPU only).
- What you have already read, so the answer can start from there.

## What not to ask in public

- **Security problems:** follow the [security policy](https://github.com/Cassandra-Collective/.github/blob/main/SECURITY.md) instead.
- **Conduct concerns:** contact the address in the [code of conduct](https://github.com/Cassandra-Collective/.github/blob/main/CODE_OF_CONDUCT.md).
- **Secrets:** never post a token, key or password, even an expired one.

## What to expect

There is no paid support, no support contract and no guaranteed response time. The projects are maintained by volunteers, who answer when they can. A question that shows what you tried is usually answered sooner.

If an answer shows that the documentation was unclear, we treat that as a documentation bug and fix it.
